# captains-log
A widget, html5 page, and cli, to collect logs, reports, project status, milestones. First place to check with coffee in morning. 

Runs as a desktop widget in OSX, an html5 site, or cli. 

"Peel back the windows of your desktop, and see what is going on underneath"

Make visible important log reports, or status from log reports. Run checklists.

Forgot what you are doing? Can check here for progress reports from agents. 

Can follow multiple projects, each configured with their own reporting preferences, heart beat monitors, server checks, project milestones, agent summary reports, or check to see if anything is blocking progress.
